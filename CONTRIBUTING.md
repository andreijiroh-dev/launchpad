# Contributing to the personal launchpad project

The personal launchpad project is @ajhalili2006's personal issue tracker and public inbox,
the GitHub/GitLab issues way.

## Preflight checks / Prerequisites

By participating in this project, you agree to the following:

* [the Code of Conduct](./CODE_OF_CONDUCT.md)
* [Support guidelines for anything filed publicly](./docs/support.md)

## How to file issues

Use the provided issue description templates to file a new ticket. If you are unsure which
to use, please use the "General" template.
